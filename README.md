## 利用上の注意

- 報告書の数値は、作成時点の Web 検索結果をもとにしています。求人条件は変わりやすいため、社内資料や提案に使う前に、各求人の元の掲載ページで最新の条件を確認してください。

## 資料を追加するとき

- ファイル名は `種別_対象.md`（例：`競合調査報告書_〇〇.md`）の形にそろえます。
- 追加したら、上の「ファイル一覧」に1行足してください。
