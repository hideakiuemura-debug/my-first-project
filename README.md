# my-first-project

求人の競合調査など、採用・求人まわりの調査資料をまとめるリポジトリです。

## ファイル一覧

| ファイル | 内容 | 作成日 |
|---|---|---|
| [競合調査報告書_東京エレクトロン宮城.md](./競合調査報告書_東京エレクトロン宮城.md) | ジョブハウス掲載「東京エレクトロン宮城（宮城県黒川郡大和町）」半導体製造装置 組立求人の競合調査。近隣の競合求人5件との比較、強み・弱みの分析、改善提案 | 2026-10-05 |

## 利用上の注意

- 報告書の数値は、作成時点の Web 検索結果をもとにしています。求人条件は変わりやすいため、社内資料や提案に使う前に、各求人の元の掲載ページで最新の条件を確認してください。

## 資料を追加するとき

- ファイル名は `種別_対象.md`（例：`競合調査報告書_〇〇.md`）の形にそろえます。
- 追加したら、上の「ファイル一覧」に1行足してください。
