## 0. 狙い

**表の縦幅を最小にすること。** 同じ内容でも列幅の配り方で高さは倍近く変わる。列幅は「見た目の均等さ」ではなく「その列が何行になるか」で決める。意味が変わらない範囲で本文の文字を削るのも是（「優先度は低い」→「優先度低い」、読点を1つ抜く）。

## 1. 列幅は変えない（既存ページを更新するとき）

- 取得したHTMLの `data-width` / `data-colwidth` はそのままの値で維持。人が手で調整している
- 列数・列の並びも変えない
- `data-colwidth` はヘッダ行・ボディ行の**全セル**に付ける（1つでも欠けると等分にリセット）
- 新規に表を作るとき、「列幅を調整して」と明示されたとき、中身を変えたときだけ §3 で決め直す
- 未公開ドラフトの変更はAPIから見えない。書き込む側は直前に最新版を取得する
- `updateConfluencePage` はバージョン指定がなく、衝突しても警告なく上書きする。取得→作成→書き込みの間は編集しないよう伝える（このスキルは子ページにだけ書くので、親ページとは衝突しない）

## 2. セルの中身は必ず「1段落」

- 空の `<p>` を残さない ← 縦幅が伸びる最大の原因
- `<br>`、セル内の `<ul>/<li>`、入れ子の表は使わない
- 列挙は「A/B/C」で1行にまとめる
- 注記・定義・凡例はセルに入れず、表の直下に1段落で書く
- 表の直後の注記と参照は `<p>※…<br>参照：…</p>` で1段落。「出典」ではなく「参照：」

## 3. 縦幅を最小化する ★最重要

### 3-1. 計算式（9/30に実機の折り返しで検証）

**必要幅 = 全角×16 ＋ 数字×9 ＋ 英小文字×8 ＋ 英大文字×11 ＋ %&@×13 ＋ ( ) , . / -×5 ＋ 24px**

**1行に入る全角字数 = (幅 − 24) ÷ 16**。270px→15字、350px→20字、450px→26字、640px→38字。

手で数えず `python3 scripts/colwidth.py` で計算する。

| 例 | 必要幅 | 内訳 |
|---|---|---|
| 「無料応募比率」 | 120 | 全角6×16+24 |
| 「2,575.4万円」 | 111 | 数字5×9+記号2×5+全角2×16+24 |
| 「ブランド」 | 88 | 79だと折れる |
| 「常時80%以上」 | 119 | 112で折れた |
| 「88%・74%」 | 102 | 88で折れた |

### 3-2. 1列目は1行に収める

最長の項目名から計算する。例外：その行が他の列でどのみち2行なら、1列目が折れても行の高さは増えない。**No列は40pxで作れる。**

### 3-3. ヘッダ行も2行にしない

列名を短くして解決するのが有効：「検証期限」→「期限」、「事業部提出」→「提出」、「成立条件からの積み上げ」→「積み上げ」（定義は表の直下へ）。

### 3-4. 数値＋単位は割らない

「2,575.4万」／「円」は不可。最長の数値から逆算する。「161名」67／「集計中」72／「1,445件」81／「12,939件」90／「5,000万円」97／「2,575.4万円」111。必要幅より広く機械的に割り当てない。

### 3-5. 削った分は全部、文章列へ

推移表の最終列は270〜290px、比較表は380〜460px が目安。

### 3-6. 文章列も、まず1行を狙う

先に文字を削る。削っても入らないときだけ2行。
例：「予算44%に対し未達」→「予算44%に未達」、「広告を絞ったにもかかわらず応募は増加」→「広告を絞ったが応募は増加」。

### 3-7. 2行目に1〜2文字だけ残さない

「す。」「る。」だけが2行目に落ちるのは禁止。列を広げるか、文字を削る。

### 3-8. 全角記号を半角に

「／」→「/」（16px→5px、最も効く）、「＋」→「+」、「％」→「%」、「（）」→「()」。全角スペースは使わない。

### 3-9. 合計幅

`data-colwidth` の合計は `data-width` より5〜20px小さく。760なら740〜755。超えると列が勝手に縮む。

## 4. 体裁

- 数値セルは右寄せ：`<p style="text-align: end">123件</p>`
- 強調したい数値：`<strong><span style="color: #ff5630">…</span></strong>`（【要確認】のオレンジ #ff991f とは分ける）
- 単位が長い場合はセルから外し、表の下に「（単位：円）」
- セクション区切りは `<hr>`
- 目標などの強調ブロックは `<div data-type="panel-info"><p><strong>…</strong></p></div>`

## 5. 表の中身（全表共通）

- 文章はサマライズし、1行の字数（§3-1）を目標に削る
- 金額は万円に統一。マイナスは `△`
- 集計基準（請求月／活動月／登録月）の違う数値を混ぜない。混ぜるなら表の下に明記
- 遷移率が100%を超えるなど直感に反する数字には、表の下で理由を1行
- シートの「合計」セルは自分で計算して検算してから転記する
- 本文・箇条書き・panelも含め、行末に1〜2文字だけ残さない
- 「前期」「今期」「来期」は使わず期間を明記。日付はテキストで「9/17」

## 6. 表の種類ごとの書き分け

まず「この表は何の表か」を決めてから書く。

| 種類 | 評価記号 | 文字数 | 列の型 |
|---|---|---|---|
| ① 評価サマリー表 | 使う | 40字・2行 | 項目/実績/評価 |
| ② 推移表 | 使わない | 50字 | 指標/各月/合計・コメント |
| ③ 比較表 | 使わない | 60字 | 項目/A/B/差と意味 |
| ④ 一覧表 | 使わない | 30字 | 名称/属性1/属性2/備考 |
| ⑤ アクション表 | 使わない | 制限なし | 項目/内容/対策 または 項目/問い/判断基準 |

- ① 評価列は「◎/○/△/×」＋端的な理由。背景・言い訳は本文へ。差と評価は1セルで「+13件（◎ 7月14件・8月19件）」
- ② ない月は「—」、集計前は「集計中」。月列は狭く、余りは最終列へ
- ③ 最終列は「差の数字」と「その意味」をセットで。例「△227万円。成立条件どおりに積み上げても目標に届かない」。系列3つ以上なら5列可
- ④ 評価・所感を入れない。1セル1属性。属性列は50〜90pxまで詰めてよい
- ⑤ 原則は箇条書き。表にするなら3列。全行2行以上になりやすいので §3-2 の例外が効く
- 要確認リスト（箇所/指摘/アクション）は⑤の3列型として扱う。「指摘」を文章列にする

## 7. 使ってはいけない記法

- `<ac:structured-macro>` などのstorage XML（文字列で表示される）
- `<html>` `<body>` で全体を包む

## 8. 書き込み前の自己チェック

**構造**
- 空 `<p>`／末尾の空段落／連続 `<br>` がないか
- `data-colwidth` の付け忘れがないか。合計は `data-width` より5〜20px小さいか
- セル内に `<ul>` や入れ子の表がないか

**縦幅**（`colwidth.py --widths` で確かめる）
- 1列目とヘッダ行が2行になっていないか
- 数値と単位が分かれて折り返していないか
- 文章列は、文字を削れば1行に収まらないか
- 2行目に1〜2文字だけ残っていないか
- 全角「／」を半角「/」にできないか

**中身**
- 評価記号（◎○△×）が評価サマリー表以外に紛れ込んでいないか
- 評価列が全角40文字・2行を超えていないか
- 集計基準の違う数値が混ざっていないか

## 付録A：列幅の出発点（data-width="760"、旧式で作った値。最終値は colwidth.py で出し直す）

| 表の種類 | 列数 | data-colwidth |
|---|---|---|
| 評価サマリー・アクション | 3列 | 110 / 295 / 345 |
| 比較表 | 4列 | 105 / 95 / 95 / 455 |
| 比較表（3系列＋合計） | 5列 | 105 / 115 / 115 / 115 / 300 |
| 一覧表 | 6列 | 112 / 88 / 88 / 175 / 152 / 135 |
| 推移表 | 8列 | 135 / 55 / 55 / 55 / 55 / 55 / 55 / 285 |
| 推移表 | 5列 | 120 / 88 / 88 / 88 / 366 |
| 用語集・2列表 | 2列 | 125 / 625 |

横に広げたい表は `data-width` を1011程度まで上げ、`colwidth.py --data-width 1011` で計算する。

## 付録B：よくある失敗と直し方

| 症状 | 原因 | 直し方 |
|---|---|---|
| ヘッダだけ2行になる | 列名が列幅を超えている | 列名を短くして定義を表の下に出す |
| 「万円」だけ次行に落ちる | 数値列が狭い | 最長の数値から逆算する |
| 2行目に「す。」だけ残る | 1行分をわずかに超えた | 読点を抜く／語尾を削る |
| 1列目がやたら広い | 見た目で均等に割った | 最長の項目名から逆算する |
| 表が横に広いのに縦も長い | 数値列に幅を取られている | 数値列を詰めて文章列に寄せる |
| 全部の行が3行になる | 文章が長すぎる | (幅−24)÷16 の字数を目標に削る |
| 更新したら編集が消えた | 未公開ドラフトを上書きした | 書き込み前に最新版を取得する |
